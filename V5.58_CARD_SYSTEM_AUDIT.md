# KURDESTAN V5.58 — Card System Audit

## Scope
Only the visual card system was rebuilt. Site content, card targets, language data, city data, banner and banner image were not intentionally changed.

## Final card specification
- Unified black + gold palette across all 16 cards.
- Glass / translucent layered surface with subtle blur.
- The only image element used by the card itself is `assets/kurd-logo.webp` (token logo).
- Topic identity is communicated by card number, topic icon, title and description — no photographic card backgrounds.
- Old per-card rainbow accent rules are neutralized with a final unified override.
- Responsive grid: 4 columns desktop, 3 medium, 2 tablet, 1 mobile.
- Hover/focus treatment is restrained and accessible.

## Validation targets
- 16 `.master-nav-card` elements.
- 16 `card-token-logo` elements.
- 0 `data-card-image` attributes on cards.
- No card background image declarations in the final V5.58 override.
