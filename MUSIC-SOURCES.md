## Image policy
Images are embedded as source-linked remote assets so the site can display them without adding unverified copies to the project archive. Each artist card includes a source link. For Wikimedia Commons assets, the relevant file page should be checked for the current license before redistribution. For third-party editorial/artist images, the page source is retained and the image is not represented as project-owned.

## Editorial rule
Birth/death dates and biographies are included only where a source supports them. Where sources differ, the site avoids presenting an uncertain date as absolute fact. The page distinguishes traditional/oral roles (dengbêj, stranbêj) from modern singer/composer categories.
