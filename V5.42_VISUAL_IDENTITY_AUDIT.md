# KURDESTAN V5.42 — Authentic Editorial Visual Identity Audit

## Direction
The visual system was refined toward a Kurdish cultural archive / museum / textile editorial identity rather than a crypto-dashboard aesthetic.

## Visual changes
- restrained charcoal, deep mountain green, bronze and parchment palette
- subtle low-opacity geometric weave texture
- editorial serif hierarchy for headings and card titles
- thinner borders and less glossy card surfaces
- 4-column desktop card index, 2-column tablet, 1-column mobile
- restrained bronze underline motif on cards
- reduced token-logo prominence while retaining the requested token identity
- framed hero treatment without flags
- calmer modal and academic surfaces
- improved navigation hover treatment
- mobile countdown moved using the actual `.bannerCountdown` selector

## Preservation
No card content, city data, academic source register, language data, or 16-card architecture was removed.
