# KURDESTAN V4.5 — Trust, Risk & Security

V4.5 adds a clear security/risk disclosure layer without presenting planned actions as completed facts.

## Added
- Official contract status: planned until real deployment and on-chain verification.
- Security audit status: pending until an actual audit report is published.
- Liquidity lock status: planned; four-year lock proof is required after real execution.
- Multilingual digital-asset risk notice.
- No-profit-promise / no-investment-advice language.
- User verification reminder for contract, sources and local laws.

## Editorial rule
Planned tokenomics, liquidity, vesting and roadmap items are explicitly labelled as plans unless execution evidence is published.
