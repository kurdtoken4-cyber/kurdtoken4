# Card 11 — Kurdish Cuisine Sources

Primary references used for editorial framing and images:

- Heritage.KRD — Kurdish cuisine: https://heritage.krd/ku/cuisine
- Wikimedia Commons — Kurdish cuisine category: https://commons.wikimedia.org/wiki/Category:Kurdish_cuisine
- Wikimedia Commons — Dolmeh in Kurdistan: https://commons.wikimedia.org/wiki/Category:Dolmeh_in_Kurdistan

Image credits are linked on each dish card to the individual Wikimedia Commons file page. The card intentionally distinguishes documented Kurdish food traditions from dishes shared across neighboring cuisines.
