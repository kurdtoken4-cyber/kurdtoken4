# KURDESTAN — V5.1.1 Production

نسخه‌ی استاتیک و چندزبانه (کوردی، فارسی، ئینگلیزی، تورکی، عەرەبی) بۆ GitHub Pages.

## ناوەڕۆک
- سیستەمی گۆڕینی زمان بە دووگیانی (5 زمان) لە ڕێگەی `data-ku/en/fa/tr/ar`
- مێژوو، کەلتوور، زمان، جل و بەرگ، خواردن، مۆسیقا، دەستکاری
- ئەتڵەسی ٩٦ شار بە تفکیکی چوار ناوچە (ڕۆژهەڵات، باکوور، باشوور، ڕۆژئاوا)
- بەشی KURD Token: Tokenomics، ڕوودماپ، ئاسایش و شەفافیەت

## پۆشاندنی فایل‌ها
تەنها ئەو فایلانەی کە ڕاستەوخۆ لەلایەن `index.html` بەکاردێن لێرەن:
`index.html`, `styles.css`, `script.js`, `cities-data.js`, `commons-city-images.js`,
`assets/hero-main.jpg`, `assets/kurd-logo.png`, `assets/city-placeholder.jpg`,
`assets/cities/*.svg` (وەک وێنەی جێگرەوەی خۆکارییی هەر شارێک کاتێک Wikimedia بەردەست نەبێت),
`robots.txt`, `sitemap.xml`, `site.webmanifest`, `404.html`, `.nojekyll`.

فایلە پەرەپێدان، QA و توێژینەوەی ناوخۆیی (build scripts، نسخه‌های README/QA/EVIDENCE_LEDGER
پێشووتر، cities-atlas.json/.csv) لەم پاکیجەدا نین — بۆ ئەوەی ڕیپۆی گشتی تەنها فایلی ڕاستەقینەی
وێبسایت بگرێتەوە. ئەگەر پێویستت بەوان هەیە، جیاواز و لە ڕیپۆیەکی تایبەت هەڵیانبگرە.

## گۆڕانکارییەکانی ئەم وەشانە نسبت بە فایلی سەرچاوە
- .nojekyll زیاد کرا (بۆ دڵنیایی لە جێبەجێکردنی ڕاستەوخۆ لەسەر GitHub Pages)
- فایلە دووبارەکراوەکان (٧ وێنەی هاوشێوە لە ڕەگ و assets/) و فایلی بەتاڵی `dom.html` سڕانەوە
- فایلە بەکارنەهاتووەکان (`hero-banner.png`, `telegram-profile.png`, `x-profile.png`,
  `instagram-profile.png`, `city-research-manifest.js`, `research-registry.js`,
  `clothing_section.html`, `people_section.html`) سڕانەوە، چونکە هیچ شوێنێک ئاماژەیان پێ نەدەکرا
- چەند ئیرادی ڕێنووسی زمانی کوردی (سۆرانی) چاککرانەوە: نووسینی ه‌+ZWNJ لە جیاتی ە،
  تێکەڵبوونی ژمارەی فارسی/عەرەبی، وشەی فارسی لە شوێنی کوردی (گرێدان، دەرزیکاری)،
  دووبارەبوونەوەی وشە، و بەکارهێنانی ي عەرەبی (ى) لە جیاتی ی کوردی لە چەند شوێنێک
