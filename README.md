# KURDESTAN — COMPLETE PROFESSIONAL EDITION

نسخه استاتیک حرفه‌ای و چندزبانه برای GitHub Pages.

## ساختار
- صفحه اصلی با کارت‌های موضوعی و Progressive Disclosure
- تاریخ و میراث
- چهار منطقه فرهنگی در گفتمان کردی
- اطلس زبان و گونه‌ها با توضیح اختلافات علمی
- اطلس پوشاک زن و مرد با تفکیک منطقه و زمان استفاده
- گالری لباس با Wikimedia Commons API و لینک منبع
- شهرها، غذا، موسیقی، صنایع دستی و طبیعت
- KURD Token و Tokenomics با تفکیک برنامه‌ریزی‌شده از واقعیت اجراشده
- Community و پنج کانال Telegram
- Roadmap و Sources/Data Standard

## تصاویر
گالری لباس در زمان مشاهده صفحه از Wikimedia Commons API بارگیری می‌شود و صفحه منبع هر تصویر را نمایش می‌دهد. قبل از استفاده تجاری، مجوز هر فایل را در صفحه Commons بررسی کنید.

## انتشار
محتویات این پوشه را در ریشه repository قرار دهید و GitHub Pages را فعال کنید.
