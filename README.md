# KURDTOKEN — 101 Cities Interactive Map

این بسته یک نسخه مستقل و موبایل‌پسند از سیستم «کوردستان بە یەک کلیک بناسە» است.

## فایل‌های اصلی
- `index.html` — صفحه و ساختار نقشه
- `styles.css` — طراحی تیره/طلایی و واکنش‌گرا
- `script.js` — Leaflet، فیلتر چهار بخش، Popup و دکمه‌های فعال
- `cities-data.js` — دیتای ۱۰۱ شهر
- `assets/cities/<city-slug>/1.jpg` — عکس اول شهر
- `assets/cities/<city-slug>/2.jpg` — عکس دوم شهر
- `assets/cities/<city-slug>/3.jpg` — عکس سوم شهر

## ساختار عکس واقعی
برای هر شهر سه عکس واقعی داخل پوشه خودش قرار بده. نمونه:
`assets/cities/erbil/1.jpg`
`assets/cities/erbil/2.jpg`
`assets/cities/erbil/3.jpg`

نام پوشه‌ها بر اساس نام انگلیسی شهر ساخته شده‌اند. اگر عکسی هنوز قرار داده نشده باشد، سایت خطا نمی‌دهد و تصویر جایگزین نشان می‌دهد.

## ادغام با سایت فعلی
اگر سایت فعلی KURDTOKEN فایل‌های `index.html`, `styles.css`, `script.js`, `cities-data.js` دارد، این نسخه را به صورت Drop-in استفاده کن؛ اما قبل از جایگزینی `index.html` فعلی، نسخه پشتیبان نگه دار.

## منابع بررسی نام/مختصات
نام‌ها و مختصات اولیه برای نقاط نقشه از داده‌های عمومی جغرافیایی و فهرست‌های شهری گردآوری شده‌اند. نمونه‌های مرجع:
- GeoNames / Kurdistan search
- فهرست شهرهای اقلیم کردستان
- فهرست شهرهای استان کردستان ایران
- منابع فهرست شهرهای کردی در ترکیه و سوریه

این دیتاست برای نمایش وب‌سایت است و جایگزین داده رسمی اداری/سرشماری نیست.
